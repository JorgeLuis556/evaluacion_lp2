# LPII_T2_DELACRUZ_JORGE

## Descripción
Aplicación Spring Boot para gestión de alquiler de películas.  
Migración de JPA puro a Spring Data JPA y frontend con Thymeleaf.

## Tecnologías
- Java 17
- Spring Boot 3.x
- Spring Web, DevTools, Data JPA
- Thymeleaf
- MySQL

## Cómo ejecutar
1. Crear base de datos `BD2_DELACRUZ` e importar `scrip-t1-DELACRUZ.sql` :contentReference[oaicite:0]{index=0}  
2. Ajustar `src/main/resources/application.properties` con credenciales  
3. `mvn spring-boot:run`  
4. Acceder a `http://localhost:8080/`
